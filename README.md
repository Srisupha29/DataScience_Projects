## 📂 Projects

### 🥇 1. Breast Cancer Prediction App

🔗 **Live App:** [https://breast-cancer-prediction29.streamlit.app](https://breast-cancer-prediction29.streamlit.app)

**Overview:**
A machine learning web app that predicts whether a tumor is **benign or malignant** using medical diagnostic features.

**What I did:**

* Performed **Exploratory Data Analysis (EDA)**
* Applied **Local Outlier Factor (LOF)** for outlier detection
* Built a **Random Forest Classifier model**
* Evaluated performance using accuracy & metrics
* Deployed the model using **Streamlit**

**Key Skills:**
`Machine Learning` `EDA` `Model Deployment` `Data Cleaning`
